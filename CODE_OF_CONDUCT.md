# Code of Conduct

## The Golden Rule

**Treat others as you would like to be treated.**

This simple principle guides all interactions in this project. Be respectful, be kind, and assume
good intentions. Harassment, personal attacks and discriminatory language are not tolerated.

If someone's behaviour falls short of this, tell the maintainers: open an issue, or if it is
sensitive, email info@gizmodata.com. Reports are handled confidentially; the maintainers may
warn, moderate or remove participants who don't follow this code.
