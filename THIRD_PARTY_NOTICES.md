# Third-party software in Hardcharger

Hardcharger's release binaries, `hardcharger-server` and the command-line client `hardcharger`, contain the third-party software below, linked in statically. Each component is listed with the version the release builds, its licence (an SPDX expression where there is one), the binaries and platforms it is in, and the full text of its licence and notices. Hardcharger itself is under the Apache License 2.0 (`LICENSE`).

The web UI that `hardcharger-server` embeds has notices of its own, for the JavaScript packages it is built from: `THIRD_PARTY_NOTICES-web-ui.txt` beside this file, `/ui/third-party-notices.txt` on a server with the web UI on, and the end of `hardcharger-server --licenses`.

Not listed: the C and C++ runtimes and operating-system libraries the binaries use from the system they run on, and the parts of the GCC runtime (libstdc++, libgcc) or the Microsoft C runtime that the Linux and Windows builds link statically, which their licences (the GCC Runtime Library Exception, the Visual Studio redistribution terms) allow without notices.
